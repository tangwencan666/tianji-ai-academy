# Java 集合框架

## List、Set 与 Map
List 保存有序元素并允许重复。Set 用于管理不重复元素。Map 保存键值映射，键不重复。

## HashMap 的线程安全
HashMap 本身不是线程安全的。在没有同步的并发写入场景，可能发生丢失更新等不符合预期的结果。
不要把过时实现细节当作所有 JDK 版本共有的行为。应根据所用 JDK 和具体并发操作分析问题。

ConcurrentHashMap 提供适合并发访问的操作。但先 get 再 put 的复合逻辑并不自动具备原子性。
例如计数更新可以使用 merge(key, 1, Integer::sum)，而不是把读取和写入拆开。
