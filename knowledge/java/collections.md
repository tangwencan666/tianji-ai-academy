# 集合框架

ArrayList 以可扩容数组存储引用，按索引访问通常为 O(1)，中间插入删除需要移动元素。LinkedList 是双向链表，按索引访问通常为 O(n)；已持有迭代器位置时局部插入删除无需移动其他元素，但查找位置仍有成本。不能简单认为 LinkedList 总比 ArrayList 插入快。

HashMap 不是线程安全容器。并发修改没有同步时可能出现数据竞争、可见性问题和丢失更新；不要把旧版本扩容问题当作所有版本的唯一原因。ConcurrentHashMap 提供并发映射操作，但 get 后 put 是两个调用，组合不自动原子。计数可用 merge(key,1,Integer::sum)。

Set 用于去重，Map 用于键值映射。哈希键的 equals 与 hashCode 必须保持一致；作为键后修改参与哈希的字段可能导致查找失败。

练习：为并发单词计数选择合适容器，比较随机读取一万次时两种 List 的成本。
