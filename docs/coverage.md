# 需求覆盖与后续路线

## 业务

用户、教师身份、课程、章节、课时、学习记录、学习进度、收藏、知识点、题库、考试、错题本、学习计划、学习报告均有后端实现与前端入口。正式权限由后端负责。数据库采用 `app_user` 避免保留字；额外增加学习事件、收藏、向量分块和AI调用日志表。

课程第一版免费，因此不引入金额和支付。视频为已有URL播放器，附件为URL，不含上传对象存储、视频转码或PDF解析。示例包含3门课程、9节示例讲义以及Java集合测验；多数示例讲义是教学引导，不是完整商业课程。

## 16项AI能力

| 需求 | 当前实现 |
| --- | --- |
| AI课程问答 | TutorService，课程过滤RAG与SSE |
| RAG知识库 | CourseVectorStore，文本分块/Embedding/MySQL向量/余弦检索 |
| 私人教师 | 系统提示词 + 学习工具 + 10轮窗口记忆 |
| 自动出题 | 教师发起，结构化输出，保存AI_GENERATED草稿 |
| 题目解析 | 针对自己的答题记录，结合参考答案、知识点与RAG |
| 作业批改 | 以简答题练习作为第一版作业，AI建议 + 教师最终复核 |
| 错题分析 | 自己的错题、考试、掌握度生成结构化分析 |
| 薄弱点分析 | Java统计与AI解释，避免让模型计算成绩 |
| 学习计划 | 目标/天数/预算，校验后持久化，逐日打卡 |
| 学习报告 | 近7天时长与已判分答题统计 + 累计掌握度，注明口径 |
| Chat Memory | 用户+会话唯一键，课程绑定，最近20条消息 |
| Structured Output | 出题、评分、周报、计划、大纲和教师摘要模型 |
| Tool Calling | 7个学生工具，模型请求/Java执行，有界准备阶段 |
| Learning Agent | 8步工作流、LearningAgentState、PlanValidator |
| 教师AI助手 | 简介、章节摘要、知识点、FAQ、大纲、班级汇总解释 |
| AI安全与权限 | Java权限、防作弊、工具预算、并发准入、限时、降级与元数据日志 |

教师统计工具已定义四种 `@Tool` 能力，当前备课流程由Java确定性调用后将汇总送给模型；它不是第二个自主教师Agent。学生导师使用真正由模型触发的工具调用。独立文件作业提交与教师批量作业管理可作为下一阶段。

## 可继续扩展的方向

- 真正模型联调与RAG评测集：召回率、引用正确性、无答案问题、越权注入样本。
- Qdrant/Redis向量索引、语义分段、混合检索与重排。
- 题目版本快照、课程课时编辑、教师批量导入与资料删除界面。
- 单独的作业实体、上传附件、批量批改与教师纠偏记录。
- 会话历史恢复界面、总结记忆、Token预算。
- 分布式AI租约、熔断、全链路追踪、审计导出。
- MySQL真实并发测试、Redis失效集成测试、完整端到端浏览器回归。
- GitHub学习热力图与排行榜可选，第一版优先真实闭环。

这些扩展没有冒充已完成的功能。真实模型接口已接好，但没有密钥时不能证明外部服务响应和生成质量。
