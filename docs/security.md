# 安全边界

## 已落实

- BCrypt cost 12；密码不作为响应字段。JWT HMAC签名，密钥最少32字符，有效期2小时。
- 注册DTO不接受角色。管理员才能变更角色；不能修改自己的角色，初始化不会把已存在普通admin账号提权。
- 所有 `/api/**` 除登录/注册都必须认证。前端路由守卫仅用于体验，后端权限独立生效。
- 教师写课程、章节、题目、考试和知识资料前检查课程所有权；管理员可管理全部课程。
- 学习记录、答题记录、错题、会话、计划均从当前身份推导归属。
- 学生题库不返回参考答案和解析，正式考试试卷也不返回这些字段。
- 任意进行中的正式考试会阻止AI、练习解析等辅助接口；提示注入无法跳过Java检查。
- AI工具没有任意SQL、HTTP或文件操作能力，没有切换用户的参数。
- 检索先按课程过滤；资料中的指令不升级为系统指令；前端无 `v-html` 输出。
- AI生成题需教师审核，简答题AI评分始终是建议；合法分数与置信度范围会被校验。
- Agent与工具均有明确预算。计划写入前校验真实课时、日期、时间和练习数量。
- Nginx登录/注册按IP限速；Docker仅发布本机前端端口，数据库和Redis不向宿主机开放。

## 第一版边界

本工程面向学习作品，不宣称生产级审计通过。以下限制应在部署到真实互联网前按业务需要完善：

1. 当前AI并发/考试互斥是单实例准入表。扩容前需要共享租约、过期恢复与分布式限流。
2. JWT没有刷新和注销黑名单；退出清除浏览器会话令牌，旧令牌在到期前仍有效。修改角色会在下一请求读取数据库时生效。
3. Prompt规则不能保证模型永不幻觉。课程资料质量、引用一致性、恶意提示和内容安全仍需评测；未接独立内容审核模型。
4. 学习心跳时长按服务器时间差限额；这防止直接提交巨大时长，不证明用户真的观看。完成状态允许学生自标记。
5. 试卷使用已审核题目引用，第一版不提供编辑已入库题目功能，因此没有题目版本快照。未来开放题目编辑必须增加版本/快照。
6. 未提供撤销历史账号、数据导出删除、忘记密码或真实生产身份验证流程。
7. 本地开发模式不经Nginx，登录限速应在公网入口另行配置；H2模式禁止作为生产数据库使用。
8. Chat与Embedding服务需要发送对应问题、课程资料及必要统计；接入真实学生数据前需明确告知和选择合适的数据处理配置。
9. 教师统计与掌握度为清晰易读实现，存在多次查询，规模扩大前需批量SQL或统计表。
10. 导师来源面板显示实际检索片段，但未做逐句引用归因；不能把检索命中当作答案正确证明。

## 环境配置

`.env`只保留在部署机器。正式环境使用独立密钥、TLS反向代理、数据库备份与最小权限账号。初始化管理员密码仅首次生效；不要把共享演示账号用于正式数据。数据库日志与AI调用日志均应设置适当保留期限。
